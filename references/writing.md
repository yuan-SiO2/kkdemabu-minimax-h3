# H3 分镜写作规范

写正文前读一次。用户给的台词、招式、顺序、胜负、结尾原样保留。

## 1. 名称与语言

角色、道具、武器、配饰在正文用档案中文全称；场景名只在风格头用全称，**正文用描述词**（`the mural plane`、`这条长街`）——正文写场景全名，整句话会硬成招牌。环境音与 BGM 用普通名词（`the paper`）。

### 1.1 语言归属

| 语言 | 成分 |
|---|---|
| 恒中文 | JSON 字段头；`类型`；`标题`（场景中文全名＋「-」＋中文短语，不留英文）；`统计`；名称；「补充：」标记；集界注释 |
| 恒英文 | 段首连接词；`环境音`；`BGM`；MV 固定串 |
| 随版本 | `整体风格`（英文版写英文风格名，如 `exaggerated theatrical comedy`）、`情节`、`尺度锚点`、`在场位置`、`画面质感`、`运镜方式`、`视觉钩子`、`时间段` 正文、档案正文——含结构标签（通道轴／人群层／方位）与括号说明；说话标记（`说：`／`says:`、`声音在画面外说：`／`Sound off-screen says:`） |
| 按原文 | 台词／心声／旁白内容；画面内文字（`<d>` 标签只写语言，方言不进口） |

### 1.2 四条铁律

1. **英文版只允许英文＋中文名称**。形容词要译（`青白`→`pale cool-toned`）；结构标签要译（`同前轴`→`same axis as before`、`人群层`→`crowd layer:`）；非档案物件用普通名词（`玻璃门`→`the glass door`）。
2. **名称后接英文**：`刘姐's pale skin`。
3. **标题恒中文**：英文译中文，只用「-」。
4. **补充标记写中文，其后随版本**；括号说明同理。
5. **名称逐字**：正文只用档案全名，或全名去掉括号别名后的主干（`周明瑞（克莱恩）`→`周明瑞`）。档案里查不到的名字，这个角色的外观定义就丢了。

写法示范（照这个密度）：
`same depth axis as before: passage, centred; 刘姐 frame right middle, facing frame left toward 许多多; aisle frame centre empty; the glass door at frame centre rear.`
`A bare tube light rakes across 刘姐's pale cool-toned skin at a 1:8 ratio; velvet dark falls off behind her; dust motes turn inside the beam.`
一句最多一个比喻，其余全是可拍参数。

**首次发声的那一段带一句声音短语**（20–40 字：腔调＋质感＋语速），口音写在这里；没有参考音频时，这是音色的唯一来源；成稿只按角色挂一条音色参考，不复述声学描述。

台词内容按原文，与版本无关。档案写逗号切分的一句：名称打头，要素用逗号，附加内容「，补充：…」，句号收尾；英文版半角逗号。

## 2. 段与转场

「段」＝`时间段` 的一条（镜内节拍，术语见 §10）。写手只写画面＋段首词。`情节` 写 `A → B`，不含台词。

| 段 | 写法 |
|---|---|
| 首段 | 直接写正文 |
| 切镜段 | `the camera cuts to`／`the shot transitions to`／`the shot changes to`／`the camera dynamically follows` ＋景别机位＋正文 |
| 节拍段 | `continuing the motion, `／`without a cut, `／`flowing seamlessly without cuts, `／`flowing into the finale, ` ＋正文 |

每次切段至少改变角度、景别、职责之一。平均一段 2–3 秒（单段 1.5–4.5 秒，见 §10.2），爆发点 1 秒。

**台词节拍链**：入场 → 台词 → 反应 → 台词 → 回呈 → 台词 → 打断。

- 入场：只写进入新空间的反馈（门被推开带起气流、雨声灌进来、人群转头），顺带交代地点与光比。
- 台词：一句一段，`<d>` 内只有台词；反应 0.5–1.5 秒紧贴其后（身体一晃、眼睛抬起、杯子落回桌面）。
- 回呈／打断：反问、重复一个词、把东西推回；或半句被截断（抢话、巨响、拳头落下），写完立刻转下一拍。
- 台词间只夹一拍；空镜落在镜末与峰值余波，≤2 秒且画面在变。台词 n 句 ≈ n+1 段；不够就减台词，不加滞留段。

## 3. 台词

### 3.1 预算（只查表）

| 时长 | 中文建议／红线 | 英文建议／红线 |
|---|---|---|
| 4 秒 | 6–10 / 12 | 5–8 / 10 |
| 6 秒 | 10–14 / 18 | 8–12 / 15 |
| 8 秒 | 14–19 / 24 | 12–16 / 20 |
| 10 秒 | 16–24 / 30 | 13–20 / 25 |
| 12 秒 | 20–30 / 36 | 17–25 / 30 |
| 15 秒 | 26–36 / 40 | 22–30 / 33 |

按台词实际语言取列；心声与旁白同样占时长。哽咽、爆发、长停顿取靠下一端。超预算：整句移到相邻分镜，句子保持完整。

### 3.2 写法与归属

台词写 `<d>[语种]整句</d>`，一句一整段，段内只放台词。说话方式写在「说」前。

**标签只写语言，方言与口音不进标签**（`[Chinese]`／`[English]`／`[Japanese]`／`[Korean]`）。标签是给音频模型选语言的，写成 `[东北话]` 会被当成未知语种，整句被换掉或吞掉。口音写进说话方式与音色档案：

- 中文版：`刘姐用东北口音吼：<d>[Chinese]坑爹呢？大过年的还考核！</d>`
- 英文版：`刘姐 snaps in a thick Northeastern accent: <d>[Chinese]坑爹呢？大过年的还考核！</d>`——叙述英文、名称中文、台词与标签照原文，三种成分各就各位。
- 标签里写标准语种：`<d>[Chinese]坑爹呢…</d>`；方言放说话方式与音色档案。

三问判归属：① 谁在发声（在场角色／无人称叙述=旁白）② 有没有外部接收者（能听见=画内；只有本人能感知=画外心声）③ 有没有口型（写了喊、低声=画内）。

| 原文形态 | 判为 | 写法 |
|---|---|---|
| 引号对白、有人回应 | 画内 | `角色名[方式]说：<d>…</d>` |
| 低语、耳语、气声 | 画内 | `角色名压低声音说：<d>…</d>` |
| 睡着呓语（唇微动） | 画内 | `角色名在睡梦中喃喃说：<d>…</d>` |
| 无引号无「他说」、无人回应（`痛！好痛！`） | 画外心声 | `角色名声音在画面外说：<d>…</d>`——必写全名，口型闭合 |
| 心里话、独白、回忆自语 | 画外心声 | 同上（`Sound off-screen says:`） |
| 无人称叙述 | 旁白 | `声音在画面外说：<d>…</d>`，不指名 |
| 场景、动作、器物、身体反应 | — | 只写画面，不进 `<d>` |

- 同一句只出现一次：进 `<d>` 或进画面，二选一。MV 零 `<d>`。
- 人物离画继续说话同样走画外声并接全名。
- 打斗中边打边说，一句完整落在同一段。
- 画面内文字按原文写进正文，用「显示」「浮着」引出，不进 `<d>`。
- **跨剪切台词**用 `<scenetrans>` 标：一句话被切镜打断、后半句落在下一镜时，在两镜相应位置各标一次；**被结尾截断**的话用 `<cutoff>` 标在断点。
- **会说话的角色在 `音色档案` 里各有一条**：条目缺了，这个角色就挂不上音色参考，会顶到别人的参考音上。

## 4. 镜头语言

- **位置是底稿，运动写在段里**。`在场位置` 只写静态：谁在哪一格／哪一区域、朝向、谁离画。每段写四件事：机位在哪、谁在画面哪、面朝哪、往哪走；段首起点照 `在场位置`，段末写清新位置交给下一镜。朝向锚点唯一（镜头或同框另一个人）。两人相对须同框。离画、空位、归位都落到段里（「起身出画」「座位空着、靠背留着压痕」「回到后排左座」）。完整站位只全片首镜写全，其后用「仍在／顺着」承接。
- **轴闸门**：方向词必须落在通道轴上。纵深场景（隧道、柱廊、长街）只写靠近／远离镜头、朝纵深退、迎面走来，左右只作半步微调；写成「从左走到右」就是穿墙。横向场景反之。竖向写升降。跨轴只有三种写法：通道转向（拐角、门槛）、穿体（穿过门／帘／人群）、开阔地（尽头进入广场、崖台）。
- 镜头由动作牵引；清晰度给面部、手、武器握持部，背景可拖影。
- 参照物：三四个全程可辨的地标／地平线／关键陈设，本镜内不换坐标。
- 景别：大全景／全景／中景／近景／特写（英 `wide shot`、`medium shot`、`close-up`）。
- **运镜三要素（词表内取）**：类型＋幅度＋速度，如 `The camera pushes in with small amplitude at slow speed`。类型：`Zoom`、`Push In/Pull Out`、`Pan`、`Truck`、`Tilt`、`Pedestal`、`Arc Shot`、`Tracking Shot`、`Static Shot`、`Shake`、`POV`、`Roll`；幅度 `small/large amplitude`，速度 `slow/fast speed`，中等省略。要量级时补焦段：`小幅慢速推近，24mm 转 40mm`。
- **运镜写进每段正文**：`运镜方式` 只给整镜基调，离画面最远；每段开头各写一次镜头动作（类型＋幅度＋速度），否则成片全是固定机位感。
- 末帧连续：末段写清位置、姿态、视线、道具状态（全名＋恒定标识），作为下一镜起手；下一镜首段按 §11.2 回读三件物证，跨集同样承接。

## 5. 声音字段

- `环境音`＝`overall_soundscape`：一到四句紧凑英文，只写声底、物理声与非语言人声（呼吸、笑声），写清远近与方向。道具用普通名词。
- `BGM`＝`non_diegetic_music`：一到三句英文，只写乐器、速度、节奏、强弱；无配乐写 `N/A`。场内音乐（收音机、现场乐师）写进正文。
- 场面声层三层：低频次声、结构声（金属呻吟、玻璃细裂）、介质声（碎屑打壳、火球抽气）；最大撞击后抽空一秒（耳鸣、心跳、远处余火）。
- 音量低于台词与关键动作声。英文原文优先保留。需要时末尾加 `no human voice, no music`。

## 6. 光线与构图

先定光源方位与阴影落点，再补色温与色彩，场景内不换型。句序：方位 → 软硬 → 色彩 → 阴影落点 → 背景明暗 → 空气感。

| 情绪 | 布光 | 英文取词 |
|---|---|---|
| 梦幻 | 柔和逆光，薄雾光晕、发丝轮廓光、低对比 | `soft backlight, rim light, low contrast` |
| 神秘 | 单侧硬光，半边脸进阴影、背景压暗 | `hard side light, half face in shadow, low-key` |
| 温暖 | 暖色柔光侧前方，琥珀奶油调 | `warm front-side light, amber and creamy palette` |
| 主角 | 侧后方轮廓光，主体从暗背景分离 | `heroic rim light` |
| 孤独 | 局部顶光，大片黑暗 | `narrow overhead spotlight, isolated in darkness` |
| 阴森 | 低位硬光，反常向上阴影 | `eerie uplighting, deep black` |

主色占 80%，补色一处。空气感落到可见微粒（尘埃、飞絮、雪粒／幻想风用光尘）。构图：单人／双人／过肩／主观／空镜／明暗交界；前景虚化、中景主体、远景氛围。

**巨构入画三法**：① 前景压尺（人／窗／车贴镜头下缘，巨构占上三分之二并被截断）② 明暗套层（巨构只剩轮廓，近处被火光照亮）③ 双尺度同框（近处人体动作，远处主形延伸出画）。完整入画＝小。

### 6.1 衬托：对比先写

每条画面至少一组可量的对比，写进首段与 `画面质感`：

| 轴 | 写法 |
|---|---|
| 大／小 | 前景压可读比例尺（身高、柱径、灯笼、门槛），主体被上缘截断 |
| 明／暗 | 光路是唯一亮面，暗部近死黑，亮部过曝一档 |
| 闹／静 | 全景给人群，只留一个人不动或一个空位 |
| 暖／冷 | 主色 80% 暖，补色一处冷（月、雪、窗外的蓝） |
| 多／一 | 百人过场里只有一个有动作细节 |

### 6.2 缝隙光与介质

- 光从缝隙来：门缝、柱间、窗棂、屋檐、树隙、人群肩缝。写清缝在哪、光从哪侧斜切、与镜头成夹角（不正对光源）。
- 介质必须有：浮尘、炊烟、蒸汽、雨丝、火星、呵气；写形态与流向。
- 曝光契约：亮部过曝一档、暗部死黑、光柱边缘发毛；颗粒可见但干净。
- **画面质感是可拍参数**：光源与光比／材质与反射／介质形态／高光位置，四件对几件写几件；判断词换成参数（「平」写成 1:2 光比、「高级」写成金属高光分离）。
- 光束只从缝隙与介质里来：先写缝在哪、介质是什么，再写光。

### 6.3 市井与人情层

热闹分声部（蒸汽、油锅、秤盘、风铃、孩子跑动），人群用整体短语带数量；至少一件生活证据（谁在数钱、谁把碗推回去）。留一个不在热闹里的人（蹲在台阶上的孩子、门槛上的老人）。灯火写层级：近处灯笼糊边、中景窗格、远处连成暖雾；冷色只给天光与阴影。

### 6.4 反直白

孤独／繁华落在三秒前后的变化上（先满桌未动，再一只冒热气的碗）。一镜内给两次读数，段落末把差值落在可见对象上（手停住、灯灭、门合上）。观众补全的留给画外：画面离开，声音继续。

### 6.5 唯美写实自检

缝隙光／介质／比例尺／冷暖／动静，五条中三条。少就补比例尺与介质。仅 A／B／E 写实向档位查；C／D 档改查 `styles.md` 的档内特征清单。

### 6.6 风格口味

按 `references/styles.md` 档位：`整体风格` 只有风格名，四件套由此落地。B 档要 SSS＋逆光边缘＋星尘＋材质分离；C 档不用写实尺度的微表情（要夸张，见 §11.1）、不手持晃动；E 档只取 2–3 个可执行特征。一档到底。

## 7. 质量纪律

**单段公式**：尺度建立（比例尺＋被截断的巨物）→ 介质响应（尘／火／水被谁搅动、朝哪去）→ 力的接触 → 破坏形变 → 余波静默；链上必有一个可量物理事实。

- 可视化回执：每次挥动、命中都留轨迹（刀光拖尾、风压线、斩断线、墨迹晕开）。
- 特效三段链：触发（谁、从哪发）→ 轨迹（方向、速度、拖尾）→ 命中反馈（形变、飞溅）。
- 动作写解剖学（发力与命中部位），运镜只用 §4 词表。
- 表演三层：身体（呼吸、吞咽、指节、重心）→ 微表情（睫毛、下颌、嘴角）→ 台词；转折「先压后泄」。C／D 档三层不变、幅度按 §11.1 放大到夸张尺度。效果词落成物理：震撼＝快速推近＋碎裂＋声压；唯美＝缝隙光＋介质＋逆光轮廓；张力＝距离收窄＋明暗交界落在两人之间。
- 路人只作环境（人群层整体短语＋数量），路人说话才建角色档案。
- 取景与一致性：一个空间关系，其余从主形派生，巨物被画框／云雾截断；头身结构、服装、武器持握、阵营配色、光线逻辑全片不变，变的只有微动作与粒子。
- 动静：动段 3–5 秒一次状态变化；静段 3–4 秒只做一件事（尘埃落、火舌舔舐、耳鸣、光在废墟上移）。峰值后必有静默。
- 观众视角：每场至少一镜让观众付代价（低角度被巨物吞没、前景遮挡做纵深、镜头被掀动或溅上尘土）；一镜一个视觉主张，其余降级为介质与背景。
- **镜级字数目标**：`detailed_description` 每镜 **350–500 英文词**。对白密集的镜以「说完台词」为先，但不得低于 250 词；单镜不因「只有一个镜头」而减免。中文版按同等信息量换算约 **550–800 汉字**。段内怎么摊、往哪儿加词，见 §10.5。
- **信息量下限**（低于线就回阶段二补）：每镜外观细节 ≥2 项、动作单元 ≥3 个、介质或光的变化 ≥1 处、空间锚点 ≥1 个、可写声音 ≥1 条。

## 8. 类型分支

### 8.1 首段骨架

首段写全三样：定场（景别机位、谁在哪、朝向距离）、本镜新起的动作、光影；逐字模板见 SKILL 阶段三。

全片不变的基础状态（骑乘、飞行、贴地）在首镜写死，后续继承。

### 8.2 文戏

段数取 §8.3 表靠中下。一段对白内情绪最多一次大转折，转折要有可见触发（一句台词、一个物件、一次视线）。每段只承载一次微型关系变化。潜台词：说出口的和想要的相反（「我不在乎」＝把衣角捏白）；最重的一句落在背影、手、空镜上。长短交错：短段（一次视线）接长段（一次完整反应）。切镜落在新信息、说话权、距离或道具变化时，声音连续；守 180 度轴线，跨轴前重新定场。每段至少一个物理动作（灯管闪、雨点砸窗、椅子腿刮地），纯正反打问答视为未写完。

### 8.3 武戏

| 时长 | 段数 | 切镜 |
|---|---|---|
| 4–5 秒 | 2–3 | 0–1 |
| 6–7 秒 | 2–4 | 0–2 |
| 8–9 秒 | 3–5 | 0–2 |
| 10–11 秒 | 3–6 | 0–3 |
| 12–15 秒 | 4–7 | 0–3 |

切镜上限 3 是硬约束；密度靠镜内节拍段。

**五段曲线**：开场 2 段（景别机位＋一次有力推近，接静默对峙）→ 首轮交锋 2–3 段（同步爆发、敌逼近、主角破局，崩出具体缺口）→ 升级 3–4 段（每段改景别／方位／高度／优势之一，对手两次占上风，损伤累积）→ 决胜 2–3 段（威胁→路径→命中先前那个缺口同部位，付可见代价）→ 交接 1 段（落地、余波、新威胁）。

- 首镜之后从上一镜结果接着打；落地与收尾留到该场末镜。群战以敌方主将计上风，杂兵写数量。
- 镜头接力表六项末态：末姿朝向、运动方向速度、位置高度、武器状态、敌人受击状态、持续特效；下一段至少承接四项。切镜落在动作未结束的接力点（刀锋刚接触、身体仍在旋转、被击飞途中）。
- 每个主要动作写九项：谁先动、怎样起势、朝哪移动、对方如何应对、在哪接触、什么形变、谁被迫改变位置、镜头如何跟上、什么声音同步。命中写到部位（甲片接缝、剑脊、护腕、颌侧）。
- 高速用可见证据：地面连续炸裂、碎石反向喷射、衣摆被气流拉直、背景视差与残影。连招以姿态接力：上一击的收势成为下一击的起势；受击方在同一段内接撑地、翻滚、反打。骑乘／飞行／贴地全程保持状态；大招成形后保持到终结技。
- 甩镜跟武器：近战跟挥击方向（握持的手→尖端→被劈开的甲片），远程跟投射物，法器绕轴并留一件可投射物。特效长自主色与敌色，接触处两色同炸，每效果写触发源、方向与消散。
- 大招全片一次，七型选一（法相／天象／召唤／兵器化形／环境化武／领域／变身），写全触发→长出→展开→尺度材质→压迫→散去。子弹时间全片一次，插在最强碰撞后，200–240 度绕行，结束即回全速。
- 台词落在当前段内，画面变化放在两句之间；台词与特效同段并存，先保台词说完。

### 8.4 MV

输入 .srt 歌词：正文零台词零 `<d>`，口型按策划文件字段执行，情绪靠微动作、视线、光影。意象转译（「零点零一分」→ 时钟指针特写＋手机冷光映脸）。曲线对齐歌曲结构：主歌铺垫→预副歌积聚→副歌爆发→间奏空镜→尾声收束。段切点对齐歌词行边界，歌词密集处 2–3 秒一换。两个声音字段逐字写 `Use the original audio; music and sound effects are taken from the original track.`

### 8.5 场面

主体是环境与力。段数取 §8.3 表靠上（2–3 秒一换，冲击压到 1 秒）。曲线：奇观揭示（巨构一部分入画、前景压尺、介质在光里可见、一次大幅慢速推近）→ 介质与接近（火沿迎风面爬、等离子尾迹、碎片被拉成直线，镜头被热浪推抖）→ 接触与破坏（地面翻起、水柱、尘土环；外部巨观＋内部微观）→ 内部或人物反应（灯灭、气压雾化、耳鸣压掉声音）→ 余波静默（只留一种声音与一种运动）。介质必须受力；破坏要留残留（弯折角度、玻璃颗粒大小）供下一镜起手。峰值后先给一次人的尺度（一只手、一双眼睛、一只掉了的鞋）。

## 9. 时长修复

本节只判断装不装得下；具体时长按 §10.2 排。

- 超时：台词整句移到相邻分镜 → 补过渡（动作接点、空镜、环境声桥）。组件耗时：一般动作 2–3 秒；走位 3–5 秒；道具交互 1–2 秒；情绪转变 2–3 秒；缓推 2–3 秒；全景转近景 3–4 秒。
- 武戏超容量：合并同方向动作 → 一镜连续承载多招 → 压缩非关键过渡。
- 空洞补内容（够即停）：微动作 → 声底与光影 → 情绪停顿 → 道具交互 → 缓推或焦点转移 → 画外心声。
- 场面挤不下：合并同方向介质运动，把接近—接触压进一个长段；奇观揭示与余波静默各保一段。

## 10. 镜与段的写法边界

**术语**：**镜**（＝`分镜`，一次 H3 请求）／**段**（镜内节拍，`时间段` 的一条）。两者别混用。

本文件只产 `时间段`／`环境音`／`BGM`；段内只写画面与段首词。

### 10.1 段里写什么

每段是「段首词 ＋ 画面句」：先给对象与画面位置，再写朝向、运动、光影、介质、声音来源。

编号、时间、风格开场、主体定义、摘要、保留分析各有自己的字段：`整体风格`／`画面质感`／`场景`／`在场位置`／`运镜方式` 填在档案与 `分镜情节`，其余由成稿承载。正文只装画面，字段只装参数，两边各归各位。

### 10.2 段的时间预算（镜内）

单段 ≈ 1.2 秒 ＋ 台词（中文 4.2 字/秒、英文 3.0 词/秒）＋ 0.3 秒 × 动作单元；单段落在 1.5–4.5 秒。动作单元按 `，、；` 切、每块 ≥6 字、最多计 8 块。

- 一段装多少：台词 8–12 字 ＋ 动作单元 3–5 块 ≈ 4 秒；纯台词段 ≤14 字（英文 ≤10 词）。
- **段时长只看「单元＋台词」**，词数不影响：描述段 ≤3.6 秒、含台词段 ≤4.5 秒（算法与后果见 §10.5）。
- **单段上限不是目标**：整镜台词总量仍按 §3.1 表（8 秒镜中文 ≤24 字、12 秒 ≤36、15 秒 ≤40）；段数 × 单段上限超过表就是超预算，先删台词再排段。
- 动作句用逗号／分号串（句号不切单元，全用句号会把一段压到 1.5 秒）；静态描述用句号——分法见 §10.5。
- 镜长 ÷ 段数落在 2–4 秒最稳；15 秒镜只写 3 段会被拉成 5 秒／段。

### 10.3 跨镜承接（第 2 镜起）

- 镜内前 0.9 秒是上一镜的运动惯性：第一段写承接，动作顺着上一镜走，台词接在惯性之后。
- 承接句必须带上上一镜的角色名与道具名＋标识（§11.2），否则这 0.9 秒里画面就开始改款。
- 镜末交接写在最快的一瞬，下一镜首段从惯性起手。
- 台词安全窗按**镜**算：镜内 1.0 秒后起、镜长减 1.0 秒前收（8 秒镜即 1.0–7.0 秒）。

### 10.4 三条生成契约（首镜 `画面质感` 写一次）

- 参考图负向锚定：`仅提取参考图的 A／B／C，严禁迁移 D／E／F`。
- 实体数量：`全场实体武器恒定为 N 把，所有能量投影、残影、分身均为非实体，绝不分裂出多余实体兵器或肢体`。
- 输出：`纯画面输出，无字幕、无水印、无UI`；无台词镜补 `全程双唇紧闭，无张嘴口型`。

### 10.5 密度与段长怎么配合（350–500 词不被时间吃掉）

段的时长只由三项算：1.2 秒基础 ＋ 台词（中文 4.2 字/秒、英文 3.0 词/秒）＋ 0.3 秒 × 动作单元（`，、；` 切、每块 ≥6 字、最多 8 块），落在 1.5–4.5 秒，再按镜长把各段摊匀。**词数不进公式**——写更多词不会多给时间。

| 内容 | 用什么标点 | 抢不抢时间 |
|---|---|---|
| 静态层：外观、材质、光、介质、空间关系、声音来源 | **句号**（句号不切单元） | 不抢，可以写满 |
| 可见动作、位移、接触 | **逗号／分号**；3–8 块都合法，4–6 是舒适区 | 抢，每块 0.3 秒，8 块封顶 |
| 台词 | `<d>` | 抢，单段 ≤14 汉字 |

三条用法：

1. **词数按段数摊，增量全放静态层**：8 秒镜 350–500 词 → 3 段每段 120–165、4 段 90–125、5 段 70–100（中文乘 1.6）；每段可见动作只留 1–2 个，其余用句号写材质、光线、介质、空间关系与画外声。
2. **第 9 块起不计时**：某段要塞多动作就拆成两段（段数取 §8.3 表上限）。
3. **块数不是表演密度指标**：一段 1.6–2.7 秒只演 1–2 个可见状态变化；为抢时间把动作堆到 8 块，只会让同一段时间里塞进更多动作、演得更糊。
4. **对白密集的镜别硬凑**：8 秒镜台词 14–19 字已占 3.3–4.5 秒，词数目标降到 250–300，先保台词说完。

自查：`该段词数 ÷ 该段时长` 若明显超过 60 词/秒，说明动作写成了动词链而不是画面描述——回去把动作句改成分号块、把材质与光改成句号句。

## 11. 表现力与物证连贯

### 11.1 夸张档：把「夸张」写成参数

`整体风格` 是夸张戏剧（C／D）时，每镜从 `references/gags.md` 挑 1–2 个机关，按「触发 → 机关 → 残留」写进正文，并写一条表情变化链：初态五官位置 → 触发（台词／物件／视线）→ 肌肉位移 → 残留定格形状。

| 维度 | 写法 |
|---|---|
| 幅度 | 五官位移用指宽／眼白露出／下巴前伸量；动作行程 ≥ 半个人高 |
| 节奏 | 反向预备 0.1–0.2 秒 → 0.2 秒爆发（过冲越过终点再弹回）→ 定格 0.5–1 秒 → 回收 |
| 形变 | 挤压拉伸：沿运动方向拉长 10–20％、落地压扁回弹；头发衣摆胡须滞后两帧 |
| 顺序 | 眼 → 眉 → 嘴 → 肩 → 手，一次一处再连锁 |
| 慢半拍 | 先僵 0.3–0.5 秒只让眼珠动，再整体炸开 |

**本节整节只对 C／D 档生效**：A／B／E 写实向档位照 §7 的表演三层写（呼吸、睫毛、下颌、指节），`微微`／`不易察觉` 在写实档是合法写法。

- 每句台词落地配一张看得见的脸：眉抬到发际线下一指、眼白全露、下巴前伸两指，三处至少一处。
- 表情一律写到夸张尺度；需要冷面时写「冷面」并同镜解冻（裂一口气、嘴角抽一下）——冷面只占一拍。
- 走位写重心：先沉后备、步子迈过肩宽、停步带回弹；一次只动一处，再连锁到全身。
- 表情句的主谓语写位移与变形：`下巴抬到露出喉结的弧度`、`视线砸在盒盖上再弹回来`、`腮帮鼓起来又瘪下去`。写「位」的句型（`jaw set`／`chin level`／`eyes stay`）留给写实档。

### 11.2 跨镜物证：同一个名字用到底

正文写通称（`盒子`／`少女`／`那把刀`），模型只能自由脑补——上一镜的显卡盒子，下一镜就成普通盒子。

- **每段主角与主道具都写档案全名**（每段至少一次）。代词与通称最多撑一句：「她把显卡盒子塞进背包，盒子侧面黄质保贴翘着」。
- **恒定标识三件套**：颜色／破损／可读文字，在档案 `补充：` 里定死（`补充：侧面黄质保贴、左上角压瘪、丝印 RTX`）；正文每次出现至少重复两件（`仍是那张翘角的黄质保贴`）。
- **一镜内至少提两次**：主道具在镜内起手提一次、收束再提一次，正文里它的名字至少出现 2 次；只提一次＝下一个镜必漂。
- **镜首三件物证回读**：谁站在哪＋朝向 → 手上／身边的道具全名＋标识 → 光从哪来。三件缺一，这一镜必漂。
- **状态链**：开合、在谁手里、哪只手、朝向；易手在本镜内闭环（递出 → 接住 → 旧主人手空）。
- **款式全片一套**：角色服装、道具型号、武器柄形照档案走；剧本写了改动才改。
- `出现道具` 清单与档案里的恒定标识两样齐备，这一镜才成立。
