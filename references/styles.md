# 风格库：确认菜单 + 写法 + 落点

风格是开工确认的输入，不是写手默认的形容词。

## 0. 三条铁律

1. **先确认再动笔**：给 2–3 个具体候选＋默认（每个都说得清四件套），等用户点头。
2. **风格卡四件套**：材质与质感／调色／镜头语言／表演尺度。四件齐才算定了风格；`整体风格` 只写风格名，细节落到 `画面质感`／`运镜方式`／段内表演。
3. **一档到底**：全片一个口味。

## 1. 确认菜单

| 档 | 观感 | 题材 | 默认 |
|---|---|---|---|
| A 写实电影感 | 真实光比、自然肤色、手持微晃、颗粒 | 都市、犯罪、战争、现实 | ✓ |
| B 2.5D 史诗唯美 CG | 二维精修五官＋三维体积光、瓷润皮肤、逆光边缘、星尘 | 仙侠、玄幻、史诗、游戏 PV | |
| C 夸张戏剧·喜剧 | 表情肢体大幅夸张、反应慢半拍再爆、卡通拟音 | 喜剧、段子、儿童 | |
| D 夸张戏剧·舞台 | 定格停顿、对称正面、慢镜、集体调度 | 正剧高潮、宣传片、戏曲 | |
| E 导演风格套餐 | 按题材取一位导演的习惯镜头语言＋调色 | 见 §4 | |
| F 用户自定义 | 按参考片／截图反写四件套 | 任意 | |

提问：`风格我建议 E·王家卫（都市霓虹、慢门抽帧）或 A 冷调低饱和，也可以走 B 2.5D 史诗唯美 CG。你定哪档？有参考片发我，我按它写风格卡。`

## 2. B 档：2.5D 史诗唯美 CG（必备档）

- 材质：瓷润皮肤次表面散射（SSS）、发丝分层、刺绣与多层薄纱有真实空气阻力、金属／冰晶／刺绣三种高光分离。
- 调色：高反差天鹅绒暗调，主色 80%、补色一处；亮部过曝一档、暗部近死黑。
- 镜头：逆光与侧逆光塑形（边缘光勾发丝、肩线、器物棱角）、受控十字星芒、悬浮星尘与体积光；焦段 50–85mm。
- 表演：写实微表情；动作幅度大于真人、小于卡通。

`画面质感` 模板：`2.5D 史诗唯美 CG 质感，瓷润皮肤次表面散射，逆光边缘光勾出发丝与肩线；天鹅绒暗调打底，亮部过曝一档、暗部近死黑；金属、冰晶与刺绣高光分离，高光处受控十字星芒，空气中悬浮星尘与体积光。`

英文取词：`2.5D stylized CG, cel-shaded rim light, subsurface scattering skin, velvet low-key palette, controlled starburst glints, floating dust bokeh, material separation`
取词落在：瓷润皮肤、三脚架级稳定、高对比压暗、分离高光。

## 3. C／D 档：夸张戏剧

**C 喜剧**：夸张＝幅度×节奏×形变，三样都写数（参数表见 `writing.md` §11.1）：动作行程 ≥ 半个人高、五官位移用指宽、反向预备→爆发过冲→定格拉长→回收、挤压拉伸沿运动方向拉长 10–20％。反应慢半拍＝先僵 0.3–0.5 秒只让眼珠动再炸开。连锁按 眼→眉→嘴→肩→手，一次一处，**全身同时动就是机器人**。镜头：广角怼脸 24–28mm＋固定机位＋突然推近，1–2 秒快切；高饱和暖调；夸张拟音进 `环境音`（boing／咔哒／弹簧声）。表情一律写到夸张尺度；冷面只占一拍并同镜解冻；机位广角稳、景深深，全身幅度看得见。

**D 舞台**：起—停—落，一句话说完停两拍；对称构图、正面大特写、低机位仰拍、长焦压人；高反差单色压色，天空留白。

## 4. E 档：导演套餐

只取 2–3 个可执行特征（镜头 1 条＋调色 1 条＋构图 1 条）。写「像某某」没用，写参数才有用。

| 套餐 | 镜头＋调色（各取 1–2 条） | 取词 |
|---|---|---|
| 张艺谋 | 单色块分场、中轴对称俯拍；浓烈胶片色，红蓝绿白黑分场 | `单色块分场、中轴对称俯拍、浓烈胶片色彩` |
| 王家卫 | 手持＋慢门抽帧、广角贴脸、镜面门框做前景；霓虹实景染色、暗部染色 | `慢门抽帧、广角贴脸、霓虹实景染色` |

## 5. 题材 → 候选

仙侠／游戏 PV → B 或张艺谋；古装／武侠 → 张艺谋或 D；末日 → 废土或芬奇；科幻巨构 → 维伦纽瓦；都市情感 → 王家卫；犯罪悬疑 → 芬奇或库布里克；喜剧 → C。

## 6. 落点

| 内容 | 字段 |
|---|---|
| 风格名＋一两个限定词 | `整体风格`（随版本：中文版中文名，英文版英文名；成稿开头的风格句就是它） |
| 材质、边缘光、颗粒、调色、迁移边界 | `画面质感`（15–100 字，迁移边界只在首镜写一次） |
| 光线型、介质、空间轴 | `场景` |
| 焦段与运镜 | `运镜方式`（词表内类型＋幅度＋速度，可加 mm） |
| 表演尺度 | `时间段` 正文 |

## 7. 落盘前只查三条

1. 风格问过用户；`整体风格` 是风格名。
2. 四件套齐且全片一档。
3. 全片只用本档特征（C／D 走 `writing.md` §11.1 的夸张参数；B 有 SSS＋边缘光＋星尘＋材质分离；E 只取 2–3 特征）。

交付前以 `SKILL.md` 自检第 11 条为准。

## 8. 脚本风格（阶段一第二问：画风之外再选一件）

画风档 A–F 决定**长什么样**；脚本风格决定**怎么演、怎么抖包袱、笑点从哪来**。两件分开问，写进 `剧本.md` 的「手法」行与「表演死点」，不写进 `整体风格`（那里只放画风名）。

| 脚本风格 | 定位（冲突从哪来） | 单集三段怎么走 | 机关密度 | 台词 | 画风搭配 |
|---|---|---|---|---|---|
| 闹剧 slapstick | 身体与物理出丑 | 钩子用一次狼狈／升级连着摔／留扣在「他还没发现」 | 2／镜，可连发 | 极短、拟声词多 | C |
| 冷面 deadpan | 场面越荒唐，人越平静 | 钩子一句平淡实话／升级是别人炸／留扣在主角无动于衷 | ≤1／镜，只给背景与道具 | 短、不带情绪，越平静越毒 | A／C |
| 讽刺 satire | 用体制话说荒唐事 | 钩子是官腔／升级是流程把人碾过去／留扣在一纸通知 | ≤1／镜，机关多在公文、屏幕、招牌 | 术语与口语错位，骂意藏在流程里 | C／D |
| 荒诞 absurd | 规则自洽但前提荒谬 | 钩子先接受一个怪设定／升级把它推到极限／留扣在设定再变一次 | 1–2／镜，机关作用于**世界**而非脸 | 一本正经说胡话 | C／D／B |
| 温情 warm | 没说出口的那句话 | 钩子是一个小动作／升级是误会加深一步／留扣在一个没递出去的东西 | 0／镜 | 半句话、留白、反问 | A／B |
| 爽剧 catharsis | 压迫 → 兑现 | 钩子先挨打（压迫）／升级给期待信号／留扣在反击起手 | 爆发那一下 1 个 | 短、带立场、一句一刀 | A／C |
| 悬疑 mystery | 信息差 | 钩子给一件解释不通的事／升级收窄嫌疑／留扣在证据刚露一半 | 0–1，机关只做生理反应 | 问句多、答非所问 | A／芬奇 |
| 群像 ensemble | 几拨人各说各话 | 钩子三人同时进场／升级交叉误会／留扣在两条线撞上 | 1–2，分散在不同人身上 | 一人一句、抢话 | C／D |

**爽点三零件**（爽剧、闹剧通用）：压迫（先把人按到墙角）→ 期待（前面埋一个「他能翻」的信号）→ 兑现（一个具体动作或一句台词完成反击）。缺压迫的反击是轻的，缺期待的反转是硬的。

## 9. 单集三段与 beat 先行

单集按三段咬合，别写成「三幕剧的缩小版」：

1. **开场钩子（3 秒内）**：一巴掌、门被踹开、身份被叫破、证据亮出、一句狠话——第一秒就有事发生。
2. **矛盾升级**：误会加深、反派加码、主角反击、信息揭露——每一场都推进一步。
3. **集末留扣（cliffhanger）**：动作中断（手刚碰门把）、信息差（观众知道、角色不知道）、二选一、反常救援——收在一件正在发生的动作上。

动笔顺序：先写**场戏清单**（本集目标／开场钩子／关键 beats／爽点位置／集末钩子），再填台词与〔〕动作。每集写完后单独写一句「下一集的第一反应」——只能写出「众人愣住」，说明钩子不够具体。

台词四则：单句 ≤20 字；一句推动一个动作或一个决定；不靠台词解释前情；冲突句要带立场。

**出处**：喜剧六型（讽刺／幽默／欢乐／正剧／荒诞／闹剧）、「可笑性来自矛盾、对旁人无伤」的界定见百科「喜剧」条（源出亚里士多德《诗学》）；十二动画原则（挤压与拉伸、预期动作、跟随与重叠、缓入缓出、弧线、次要动作、节奏、夸张、立体造型、吸引力…）出自 Johnston & Thomas《生命的幻象》1981；单集三段、爽点三零件、beat 先行、台词四则取自竖屏短剧创作方法论（猫斯卡《竖屏短剧剧本工艺手册》等）。
