# 夸张喜剧机关库（C／D 档）

C／D 档不是把形容词加重，是**换一套物理**：脸能弹、下巴能掉、身体能拉长、镜头能被撞飞。每镜挑 1–2 个机关，按「触发 → 机关（带参数）→ 残留」写进正文。

- 机关写可拍参数：位移量、帧数、回弹次数、声音（见 `writing.md` §11.1）。
- 同一机关隔两镜再复用；脸上一次、身上一次，一段只放一个。
- 机关之后接一个真实反应（台词、走位、物证变化）。
- 主语换成档案里的角色名，可直接进英文版正文。

## G4 时间与镜头

| 编号 | 机关 | 写法 |
|---|---|---|
| G4-01 | 定格 | 峰值定格三帧、只有一粒尘在动 |
| G4-02 | 抖动 | 六帧硬抖、脚不离地 |
| G4-03 | 慢半拍 | 先僵 0.3–0.5 秒只让眼珠动，再整体炸开 |
| G4-04 | 抽帧 | 一拍二、动作一节节顿下来 |
| G4-05 | smear 拖影 | 身体拉成扇形拖影、速度只剩一条线 |
| G4-06 | 镜头被弹 | 撞击把镜头掀开半米再晃回 |
| G4-07 | 广角怼脸 | 24mm 距鼻尖 20cm、鼻子占半屏 |

镜头类机关落到词表原句：G4-06 → `The camera shakes strongly`（轻的用 `The camera shakes slightly`）；G4-07 → 景别 `close-up` 24mm 怼到鼻尖 20cm，运动最多一条（`The camera pushes in with large amplitude at fast speed` 或 `The camera holds a static shot`）。

## 组合与红线

- **三段式**：触发（一句台词／一个物证／一次视线）→ 机关（G 编号＋参数）→ 残留（回弹、塌陷、定格）。残留是记性。
- **反差式**：机关越大，回弹后越平静（`snaps back to a flat face and continues`）——这是冷面的唯一合法用法。
- **连锁式**：眼 → 眉 → 嘴 → 肩 → 手，一次一处。
- **对位式**：主角冷面、背景爆机关；或全场静音只有主角在炸。
- **尺度停在滑稽**：伤只放在姿态与表情上（跌倒、撞墙、被压扁）；血、断骨、恶心细节属于别的类型（亚里士多德：对旁人无伤、不致引起痛感）。
- **相悖律**：笑点来自「想要什么 vs 结果落到什么」的相悖，差越离谱越好笑。
- 机关写在人物身上：`his eyes shoot out on steel springs`（他）而不是 `全场爆笑`（观众）。
- **出处**：十二动画原则（挤压与拉伸、预期动作、跟随与重叠、缓入缓出、弧线、次要动作、节奏、夸张、立体造型、吸引力）出自 Johnston & Thomas《生命的幻象》1981；完整清单与单集结构出处见 `styles.md` §7。
